# Video Labeler

A lightweight Python tool for labeling video segments (gestures, actions, etc.)
using OpenCV + PySimpleGUI.

## Structure
- `src/`: code modules (GUI, video utils, label storage)
- `data/raw_videos/`: input videos
- `data/labeled/`: output annotations
- `data/cache/`: optional thumbnails or intermediates

## Run
```bash
python -m src.main
```
